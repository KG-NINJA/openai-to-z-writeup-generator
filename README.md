# OpenAI to Z Writeup Generator

This repository generates a Markdown writeup for the [OpenAI to Z Challenge](https://www.kaggle.com/competitions/openai-to-z-challenge).

## Usage

1. Fill `results.json` with your NDVI & cultural analysis.
2. Edit `template.md` if necessary.
3. Run:

```bash
python report_generator.py
```

4. Check `generated_report.md` for the final writeup.
